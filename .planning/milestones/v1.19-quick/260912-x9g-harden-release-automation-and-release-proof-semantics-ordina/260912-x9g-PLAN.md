## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| GitHub push/merge metadata to release workflow | Commit messages and PR metadata are untrusted inputs to release-suppression decisions. |
| Release Please token selection to CI bootstrap | PAT presence changes whether native PR events are reliable; the fallback must explicitly create required CI evidence. |
| Detached CrossWake source to local proof task | A separately checked-out repository supplies AST and executable tests whose claimed proof must be both reachable and pinned. |
| Git index/worktree to release operator | Staged, unstaged, ignored, and untracked paths cross into the release cleanliness decision. |

| T-x9g-02 | Tampering / Repudiation | Release-PR CI bootstrap under GITHUB_TOKEN fallback | high | mitigate | Dispatch exact-branch `ci.yml` whenever an open pending PR exists and PAT is absent or the PR was not freshly updated; mutation-test the predicate and preserve downstream exact-SHA `ci-gate`. |
