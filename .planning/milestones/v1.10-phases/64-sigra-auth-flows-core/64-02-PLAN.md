## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Sigra auth secrets → Chimeway persistence | Only identifier params cross `Chimeway.trigger/3`; URL/code live in Sigra `PendingDelivery` until `rendering/2` (D-07, OQ-1). |
| Chimeway trace DB → operator surfaces | `get_trace/1` must not expose raw token, code, or URL — enforced by integration tests (D-09). |
| Sigra Oban job args → Chimeway | `Sigra.Delivery` job args may still hold secrets — out of ECOS-09 scope; Chimeway path must not mirror (research §6.4). |
| Host Application.start/2 → integration | Chimeway never auto-triggers; host or test calls `dispatch_*` explicitly (D-02). |

| T-64-06 | V8.3.1 | Information Disclosure | secrets in telemetry meta | mitigate | `safe_meta/1` allowlist; integration tests refute sensitive substrings on dispatch/attempt spans. |
