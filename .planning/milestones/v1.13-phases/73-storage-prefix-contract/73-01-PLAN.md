<must_haves>
- Host apps have exactly two valid runtime storage-prefix representations in code: `"chimeway"` and `false`.
- Invalid values include missing config, `nil`, `"public"`, arbitrary strings, functions, MFA-like tuples, and tenant/dynamic-derived values.
- `prefix: false` returns repo options without `:prefix`.
- `"chimeway"` returns repo options containing `prefix: "chimeway"` unless the caller already supplied `:prefix`.
- The contract does not use compile-time schema prefixes, process-local state, database schema-existence checks, or context-private prefix logic.
</must_haves>
