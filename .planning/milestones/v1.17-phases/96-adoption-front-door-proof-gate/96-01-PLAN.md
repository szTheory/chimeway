<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| CLI argv → Mix task | Untrusted selector input chooses whether and which proof path may run. |
| Built archive → unpacked root | A package archive, digest, metadata, tar entries, and filesystem paths cross into executable fixture loading. |
| Generated consumer → runner output | Subprocess output and caught failures may contain sensitive host, database, payload, recipient, credential, or filesystem data. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-96-01 | Tampering | `Mix.Tasks.Verify.AdoptionPaths.run/1` | high | mitigate | Strict `OptionParser` allowlist rejects unknown, duplicate, positional, and malformed input before runner load or proof output; tagged negative contracts prove it. |
| T-96-02 | Tampering | `ArtifactArchive` validation | high | mitigate | Preserve lowercase SHA-256 comparison, Hex metadata/member checks, safe tar paths, single-root containment, and cleanup; mutate archive/digest fixtures to prove fail-closed behavior. |
| T-96-03 | Information Disclosure | `AdoptionProofRunner` failure boundary | high | mitigate | Catch without rendering values; output only fixed path/stage/status/rerun fields and test forbidden diagnostic classes. |
| T-96-04 | Spoofing | `CHIMEWAY_*_PROOF` consumption | high | mitigate | Accept exactly one matching record and reuse fixture allowlist/provenance parsers; reject missing, duplicate, malformed, unsafe, and mismatched prefixes before PASS. |
| T-96-05 | Denial of Service | aggregate serial proof | low | accept | Three bounded paths run serially and stop on first failure; CI timeout is added in Plan 02, so uncontrolled fan-out is absent. |
