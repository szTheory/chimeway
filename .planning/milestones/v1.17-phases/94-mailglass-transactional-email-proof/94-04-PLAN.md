## Security posture

- **Blocking threshold:** high. All high-severity threats below are mitigated and must be covered by automated release-gate contracts before execution can complete.

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| generated consumer stdout -> `parse_mailglass_evidence!/1` | The subprocess text is untrusted even when its field names are allowlisted; both structure and values must be authenticated against the deterministic local proof contract. |
| parsed evidence -> adopter/CI output | Only fixed stable identity and lifecycle facts may cross; recipient/content/credential/provider/database/config/metadata values must fail closed. |
| textual timeline -> lifecycle validation | Untrusted event tokens must remain binaries and must not create VM atoms or spoof lifecycle order. |
