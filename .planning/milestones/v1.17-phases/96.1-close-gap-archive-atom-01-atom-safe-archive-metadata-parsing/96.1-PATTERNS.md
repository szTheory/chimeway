## Shared Patterns

### Immutable-byte validation and callback isolation

**Source:** `priv/adoption_proof/artifact_archive.ex:34-56`  
**Apply to:** Parser replacement and every hostile test.

Digest the opened binary before outer-tar interpretation, parse metadata before extraction, validate root/version before calling the callback, and assert failed validation never invokes the callback.

### Bounded linear processing

**Source:** `priv/adoption_proof/artifact_archive.ex:143-160`, `:220-227`, `:270-273`  
**Apply to:** Metadata parser.

Use existing module attributes and incremental counters; reject on the first size, depth, or entry-count overflow. Accumulate lists in reverse and reverse once, matching the inflater's `chunks` pattern rather than repeatedly concatenating lists.
