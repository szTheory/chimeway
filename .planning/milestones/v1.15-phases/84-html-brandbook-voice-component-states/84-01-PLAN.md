## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| disk→browser (file://) | The book is opened directly from disk; the browser origin is opaque, so any cross-file load is CORS-blocked |
| book snippet→host app | A host app may copy a `.cwb-*` snippet; book CSS must not leak into or be leaked into by host styles (BOOK-02) |
| shipped asset→inlined mark | Inlined logo `d=` paths can silently drift from the Phase-83 SSOT assets |

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
