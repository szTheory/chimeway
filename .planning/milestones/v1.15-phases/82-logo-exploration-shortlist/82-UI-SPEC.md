# Phase 82 — UI Design Contract

> Visual and interaction contract for the logo exploration & shortlist phase. Generated by gsd-ui-researcher, verified by gsd-ui-checker.
>
> **Phase surface:** this is a doc/asset phase, not an app screen. The "UI" is (a) `notes/logo-options.md` with inline `<svg>` logo directions + per-direction proof strips, and (b) an **ephemeral, uncommitted** `file://`-safe HTML gallery in the session scratchpad (D-13) so a human can eyeball marks at real scale. No React/Next/Vite, no server, no build step. All visuals draw exclusively from the reconciled `--cw-*` token layer (`brandbook/tokens/tokens.css`).

## Spacing Scale

The doc + gallery layout consume the token spacing scale verbatim (`brandbook/tokens/tokens.css`, all multiples of 4). No new spacing values are invented.

| Token | Value | Usage |
|-------|-------|-------|
| `--cw-space-xs` | 4px | Inline SVG stroke gaps, proof-strip cell padding |
| `--cw-space-sm` | 8px | Compact spacing between mark and caption |
| `--cw-space-md` | 16px | Default gap between proof-strip variants (16 / mono / inverse) |
| `--cw-space-lg` | 24px | Gap between a direction's mark and its rationale block |
| `--cw-space-xl` | 32px | Gap between directions in the gallery |
| `--cw-space-2xl` | 48px | Major section breaks (shortlist vs rejected) |
| `--cw-space-3xl` | 64px | Page-level top/bottom padding in the gallery |

**Logo-geometry spacing rules (this phase's exceptions):**
- Clear-space around any mark = height of the lowercase `c` in the wordmark (D-12).
- Logomark minimum size 16px, preferred 24px; full horizontal lockup minimum 120px wide (D-12).
- Mark and wordmark sit at unified-unit distance — no visible icon-left/text-right gap (D-07).

## Typography

Wordmark and gallery type use the token type scale verbatim. Wordmark is always lowercase `chimeway` in the graphic; title-case "Chimeway" only in prose (never inside a mark).

| Role | Size | Weight | Line Height |
|------|------|--------|-------------|
| Wordmark (Inter base, `<text>` or hand-drawn `<path>`) | optical, sized per lockup | `--cw-font-weight-semibold` (600) primary; `--cw-font-weight-regular` (400) permitted for lighter directions | n/a (single line) |
| Gallery body / rationale | `--cw-font-size-body` (16px) | 400 | `--cw-line-height-body` (1.5) |
| Gallery label / caption (proof-strip labels, confidence) | `--cw-font-size-label` (14px) | 600 | `--cw-line-height-label` (1.35) |
| Gallery section heading (direction titles) | `--cw-font-size-heading` (20px) | 600 | `--cw-line-height-heading` (1.2) |

Exactly two weights (400 / 600), from the token layer. No other weights.

## Color

Every mark, proof strip, and gallery surface is sourced only from `--cw-*` tokens (D-11). No gradients, drop shadows, stretch, or skew inside any mark.

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `--cw-paper` #fffdf8 | Light gallery/proof-strip background; mark-drawing canvas |
| Secondary (30%) | `--cw-ink` #102027 | Primary mark fill in light contexts; wordmark ink |
| Accent (10%) | `--cw-teal` #0e7c86 | Single accent inside marks only |
| Inverse pairing | `--cw-paper` #fffdf8 on `--cw-night` #07131a | Inverse (dark) proof variant |

**Accent reserved for:** the single teal accent element within a mark (e.g. one signal-arc, one route node, or the flourished glyph terminal) — never more than one accent idea per direction (D-05), never applied to the whole wordmark, never used for UI chrome. Mono variant collapses everything to one-color `--cw-ink` (D-11).

**Destructive:** not applicable — this phase has no destructive actions. No `--cw-danger` usage.

**Hard color constraints (D-11):** mark = `--cw-ink` primary + `--cw-teal` single accent; mono = one-color ink; inverse = paper-on-night. No gradients, no drop shadows, no filter inversion.

## Copywriting Contract

This phase ships a decision document, not a product screen, so the copy contract governs the **recommendation vocabulary and proof-strip labels** rather than product CTAs. Every direction must use this exact vocabulary so Phase 83 can compare on equal terms (NOTES-02 / D-02).

| Element | Copy |
|---------|------|
| Per-direction verdict (required) | One of exactly: `Ship` / `Defer` / `Reject` — plus a confidence tag `Confidence: High` / `Confidence: Medium` / `Confidence: Low` |
| Per-direction rationale block | `Concept:` (the ≤2 visual ideas + metaphor) · `Pros:` · `Cons:` · `Recommendation:` — cohesive, not a buffet (NOTES-01 shape) |
| Proof-strip labels | `16px` · `Mono` · `Inverse` · `Clear-space` · `Min-size` (D-12) |
| Empty state | Not applicable — the artifact is only valid when it presents 3–5 fully-worked directions (5 authored per D-03). An empty/partial `logo-options.md` fails LOGO-01, so no empty-state copy exists by design. |
| Error state | Not applicable — static doc/SVG, no runtime failure surface. Gate-failure is expressed in-doc: a candidate that fails 16px/mono/inverse is moved to the Rejected section with the reason recorded inline, never shipped as shortlist. |
| Destructive confirmation | Not applicable — no destructive actions in this phase. |

**Wordmark casing rule:** lowercase `chimeway` in every graphic/mark; title-case "Chimeway" only in surrounding prose (D — specifics + VOICE-03 precedent).

## Phase-Specific Legibility Gates (checker-verifiable)

Every **shortlisted** direction must embed an inline proof strip demonstrating all of the following before it can be labeled `Ship`/`Defer` (D-12, LOGO-04 intent):

- [ ] Renders recognizable at **16px**
- [ ] Renders as **single-color mono** (`--cw-ink` only)
- [ ] Renders **inverse** (`--cw-paper` on `--cw-night`)
- [ ] **Clear-space** intent captured (= height of lowercase `c`)
- [ ] **Min-size** intent captured (logomark 16px min / 24px preferred; horizontal lockup 120px min)

**Taste gates (every direction, non-negotiable):** no rectangular/enclosing cage (D-06/LOGO-05); mark+wordmark read as one unit (D-07); primary lockup carries no subtitle (D-08); ≥2 integrated typemarks among the 5 (D-04/LOGO-02); path/route/signal/trace metaphor only — zero literal bell/clapper/note/staff (D-05/LOGO-06); brand-derived, not clipart (D-09).
