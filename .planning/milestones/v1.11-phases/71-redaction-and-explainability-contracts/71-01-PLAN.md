<threat_model>
## Trust Boundaries

| Boundary | Description |
|---|---|
| Core database rows to `Chimeway.Admin` DTOs | Durable payload/render/provider fields must not cross into admin read models. |
| Browser search input to LiveView assigns and rendered HTML | Full recipient identities, auth codes, tokens, and freeform secrets arrive as untrusted input. |
| Core trace explanation to LiveView rendering | Trace detail receives durable lifecycle facts and must render only safe, masked operator information. |
| LiveView session/params to rendered HTML | Host session and route params may contain secrets and must not be echoed. |

| T-71-03 | Information Disclosure | Search query echo in TraceSearch/Feed | mitigate | Treat full recipient/freeform search values as transient event params and render only blank or redacted display values per D-04/D-08. |
