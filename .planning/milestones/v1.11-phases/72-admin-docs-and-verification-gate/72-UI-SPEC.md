## Spacing Scale

Declared values (must be multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Status dot gaps, field hints, inline smoke-test fixture labels |
| sm | 8px | Compact row metadata, nav item spacing, copyable-ID padding |
| md | 16px | Default card padding, list gaps, form gaps, alert padding |
| lg | 24px | Page header separation, guide callout spacing, panel padding |
| xl | 32px | Main content padding on desktop, two-column grid gaps |
| 2xl | 48px | Major vertical section separation only |
| 3xl | 64px | Page-level spacing only; avoid inside cards, tables, smoke-target forms, and status badges |

Exceptions: retain Phase 69-71 exceptions. Navigation targets, row buttons, search submits, recovery submits, and confirmation controls must be at least 44px high on mobile and 40px high on desktop. Read-only status pills may be 26px minimum height. 1px borders and 3px focus outlines are allowed. Phase 72 must not introduce raw spacing values in admin UI CSS except 1px borders and the existing 3px focus treatment.

Implementation contract: if Playwright smoke needs test selectors or stable fixture wrappers, add attributes or tiny structural hooks only; do not add layout-only wrappers that alter `.cw-shell`, `.cw-sidebar`, `.cw-main`, `.cw-card`, `.cw-search-form`, `.cw-table-wrap`, `.cw-row-link`, or `.cw-confirm-form` spacing.

## Typography

| Role | Size | Weight | Line Height |
|------|------|--------|-------------|
| Body | 16px | 400 | 1.5 |
| Label | 14px | 600 | 1.35 |
| Heading | 20px | 600 | 1.2 |
| Display | 28px | 600 | 1.15 |

Typography contract:

- Use exactly the four Phase 69 font-size tokens: `--cw-font-size-label`, `--cw-font-size-body`, `--cw-font-size-heading`, and `--cw-font-size-display`.
- Use exactly two weights: `--cw-font-weight-regular: 400` and `--cw-font-weight-semibold: 600`.
- Browser-smoke-visible strings must fit at 390px width without overlap: `Command Center`, `Trace Lookup`, `Trace Detail`, `Feed Debug`, `Definitions`, `Health`, `Recovery`, `Open Trace Lookup`, `Search traces`, `Inspect feed`, and `Recover this {event|delivery}`.
- Long smoke fixture values, notification keys, delivery IDs, tenant IDs, correlation IDs, and masked recipients must use existing `overflow-wrap: anywhere` and `min-width: 0` behavior in flex/grid/table containers.
- Do not use viewport-scaled type or negative letter spacing.

Source: existing `chimeway_admin/priv/static/chimeway_admin.css`, Phase 69-71 UI-SPEC typography contracts, and SMOKE-01's requirement that the mounted console remain usable across core pages.

## Color

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | light `#fffdf8`; dark/system-dark `#07131a` | Root page background and broad reading surface |
| Secondary (30%) | light `#ffffff` / `#f7f4ea`; dark `#10232c` / `#0b1b23` | Cards, sidebar, nav, rows, inputs, tables, summary lists |
| Accent (10%) | light `#0e7c86`; dark/system-dark `#9adbcf` | Active nav item, primary search/open CTAs, selected rows, focus-adjacent highlights, `.cw-eyebrow` labels |
| Destructive | light `#b83232`; dark `#ffb3b3` button token | Recovery submit action and destructive/error state only |

Accent reserved for: active navigation, `Open Trace Lookup`, `Search traces`, `Inspect feed`, selected recovery/trace rows, focused or selected row emphasis, `.cw-eyebrow`, and informational emphasis that identifies the current operator context. Accent must not be used for every link, every status badge, docs-only decoration, or browser-smoke-only markers.

Semantic status color contract:

- Preserve Phase 71 lifecycle color mapping: `Delivered`, `Sent`, and `Provider accepted` use success/info tones according to durable facts; `Suppressed` and `Retryable failure` use warning; `Terminal failure` uses danger; unknown and DB-inferred history use neutral/info.
- Browser smoke must verify styling through computed evidence, not screenshots alone: the loaded admin shell must have a non-transparent background, readable foreground, visible sidebar/nav styles, and at least one `.cw-button--primary` or active nav accent style.
- The packaged CSS asset path is `/chimeway_admin/chimeway_admin.css`; docs and smoke must not point to a different stylesheet path.

Source: Phase 69-71 UI-SPEC color contracts, `ChimewayAdmin.Assets.css_path/0`, demo host `Plug.Static`, and Phase 72 CONTEXT D-03/D-13.

## Interaction Contract

| Surface | Contract |
|---------|----------|
| Admin mount | `/admin/chimeway` renders the real `.chimeway-admin` shell with sidebar nav, page header, and packaged CSS. A blank page, Phoenix error page, unstyled HTML page, or missing stylesheet fails the smoke gate. |
| Navigation | Sidebar labels remain `Command Center`, `Trace Lookup`, `Feed Debug`, `Definitions`, `Health`, and `Recovery`; active page keeps `aria-current="page"`. Smoke must navigate by visible labels or role selectors, not brittle CSS-only selectors. |
| Route coverage | Smoke visits `/admin/chimeway`, `/admin/chimeway/traces`, `/admin/chimeway/feed`, `/admin/chimeway/definitions`, `/admin/chimeway/health`, `/admin/chimeway/recovery`, and one `/admin/chimeway/deliveries/:delivery_id` route when seeded data provides a delivery id. |
| Trace Lookup | Search form remains `#trace-search-form` with `Mode`, `Query`, optional `Notification key`, and primary submit `Search traces`. Smoke should submit one seeded recipient or correlation search and open a trace detail if data exists. |
| Trace Detail | Detail page title is `Trace Detail`; smoke should assert safe explanation facts such as notification key, masked recipient or safe correlation, lifecycle label, and timeline/content nonblank. Do not require raw payload/provider/render fields. |
| Feed Debug | Form remains `#feed-search-form` with label `Recipient identity` and submit `Inspect feed`. Smoke should prove the form is usable and result/empty states render without echoing full PII in result rows. |
| Definitions | Page copy describes DB-inferred durable notification key/version history. Smoke and doc contracts must reject code-registry/source-skew/module-inventory claims unless implemented later. |
| Health | Metrics and problem traces render as styled cards/tables. Smoke must assert at least the page heading and one health metric/table surface is visible or the empty state is visible. |
| Recovery | Preserve Phase 70 two-panel recovery interaction. Smoke should assert `Eligible work`, `Confirm recovery`, empty/selected states, and disabled danger submit behavior when no confirmation marker is present; it should not perform broad recovery unless the fixture is intentionally isolated. |
| Auth and tenancy | Docs explain host-owned auth/tenant context and production fail-closed behavior. Browser smoke in demo/test may use permissive demo auth but must not assert production authorization succeeds by default. |
| Redaction | Smoke and docs must preserve Phase 71 redaction boundaries: no raw payloads, render data, provider bodies, secrets, tokens, auth codes, session params, or full recipient PII in rendered HTML. |
| Focus and keyboard | Existing focus-visible behavior remains: 3px outline, 3px offset, no transform on focus. Smoke may include keyboard navigation for one nav item and one form submit control. |
| Motion | Use Phase 69 motion only: 120ms color/border/background transitions and 80ms pressed feedback. Reduced-motion media query must reduce transitions to near-zero. Phase 72 does not add new animation. |

Out of scope: Phase 72 must not add new operator pages, new recovery powers, raw provider inspection, analytics dashboards, source-code registry detection, template editing, or UI framework dependencies.

## Browser Smoke Contract

| Check | Required Assertion |
|-------|--------------------|
| Server readiness | Playwright waits for the demo host before visiting `/admin/chimeway`; connection-refused or Phoenix error pages fail fast. |
| Nonblank shell | `main.chimeway-admin`, `.cw-shell`, `.cw-sidebar`, `.cw-main`, and the current page `h1` are visible. |
| Stylesheet | A stylesheet link to `/chimeway_admin/chimeway_admin.css` exists and at least one computed style from `.chimeway-admin` differs from browser defaults. |
| Navigation | All six sidebar nav items are visible; each route changes the visible page heading and active `aria-current="page"` item. |
| Responsive desktop | At 1280px wide, sidebar and main content are side by side; no text overlap, no unexpected body horizontal overflow, and key cards/tables are readable. |
| Responsive mobile | At 390px wide, navigation stacks according to Phase 69 behavior; forms/buttons fit stable widths; table overflow is contained in `.cw-table-wrap`. |
| Forms | Trace Lookup and Feed Debug forms accept text input and submit without blanking the LiveView. |
| Recovery safety | Recovery confirmation submit is disabled until the required reason and confirmation marker are present. Danger styling remains on the recovery submit. |
| Privacy | Rendered HTML checked by smoke must not include known sensitive fixture values, raw payload/provider/render field names, or full recipient PII in result rows. |

Playwright should remain a smoke harness, not a replacement for existing ExUnit coverage. Keep behavior assertions to nonblank/styled/navigable/usable proof; read-model semantics, authorization, recovery durability, and privacy leak matrices stay in ExUnit.
