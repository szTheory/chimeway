## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| obs-summary.sh -> `$GITHUB_STEP_SUMMARY` (world-readable on a public repo) | Rendered summary is publicly visible; only whitelisted cache keys/counts/durations/run-URL may cross |
| GitHub Actions REST `/jobs` -> obs-summary.sh | First-party own-run metadata read back into the job for timing |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-87-01 | Information Disclosure | obs-summary.sh summary output | high | mitigate | Whitelist emitted fields to cache keys, counts, durations, and the run URL; never echo the environment, `DATABASE_URL`, or `GH_TOKEN`. Acceptance criteria + code review enforce it. |
| T-87-02 | Tampering | values rendered into `$GITHUB_STEP_SUMMARY` | low | mitigate | Values come from first-party mix/cache/REST output and are written as markdown table cells, never `eval`'d. |
</threat_model>
