## Milestone Summary

**Key Decisions**

- Persist stable `notification_key` + version for durable identity.
- Keep explainability as a first-class product surface.
- Use adapter behaviours and optional Oban seams instead of hard vendor coupling.
- Add transactional Oban dispatch to prevent orphaned pending rows.
- Harden channel adapter resolution against runtime atom creation.

**Issues Resolved**

- Durable event/notification spine implemented.
- Delivery planning, fallback suppression, and caller-visible outcomes completed.
- Telemetry correlation and trace explanation surfaces verified.
- OSS release workflow and verification gates hardened.

**Technical Debt**

- `Chimeway.Deliveries.terminal_states/0` is currently orphaned.
- Nyquist validation coverage remains partial for some phases.
