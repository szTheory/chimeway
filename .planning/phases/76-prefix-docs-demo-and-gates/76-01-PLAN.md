<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Documentation -> operator database action | Operators may copy guide steps into production databases. |
| Documentation -> host app config | Adopters copy Chimeway and Oban prefix examples into runtime config and migrations. |
| Docs/tests -> release evidence | Contract tests represent adopter-facing truth in CI. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-76-01 | Tampering | guides/introduction/storage-prefix-upgrade.md | mitigate | Require backup, preflight counts, transaction/lock caveats, verification queries, rollback, and stop-and-restore language in guide and doc contracts. |
| T-76-02 | Repudiation | README/install/golden path docs | mitigate | Keep first-run docs short and contract-test no-silent-migration language so docs cannot later imply automatic production data movement. |
| T-76-03 | Tampering | guides/recipes/oban-integration.md | mitigate | Use Oban-owned jobs examples and contract-test that Chimeway storage prefix does not create, move, or configure oban_jobs. |
| T-76-04 | Information Disclosure | docs examples | mitigate | Avoid raw payload, render data, provider body, token, secret, auth code, or full recipient PII examples; use schema/prefix examples only. |
| T-76-SC | Tampering | package installs | accept | No npm, pip, or cargo package installs are planned; Phase 76 uses existing locked Elixir dependencies and local docs/tests. |
</threat_model>
