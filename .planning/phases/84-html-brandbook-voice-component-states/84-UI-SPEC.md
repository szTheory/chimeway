# Phase 84 — UI Design Contract

> Visual and interaction contract for the standalone `file://`-safe HTML brand book. Generated by gsd-ui-researcher, verified by gsd-ui-checker.
>
> **This phase does not design a new visual language — it renders the already-locked one.** Every token below is copied from the Phase-81 SSOT `brandbook/tokens/tokens.css`; every logo from the Phase-83 family; every copy example from `prompts/chimeway-brand-book.md`. The contract's job is to hold the executor to those sources with zero drift.

---

## Design System

| Property | Value |
|----------|-------|
| Tool | none (zero-build, zero-dependency static HTML/CSS/inline-JS — hard requirement BOOK-01) |
| Preset | not applicable (Elixir/Phoenix project; no React/Next/Vite; shadcn gate N/A) |
| Component library | none — vanilla HTML + scoped CSS (`@layer` + `@scope`, `.cw-brandbook` root, `.cwb-*` demo classes) |
| Icon / logo | inline `<svg>` where `currentColor`/theming matters; `<img src>` for fixed-color lockups + raster previews. No cross-file `<use href>` sprites (CORS-blocked under `file://`) |
| Font (sans/UI) | Inter → `ui-sans-serif, system-ui, -apple-system, BlinkMacSystemFont, "Segoe UI", sans-serif` (system fallback; NO `@font-face` bloat) |
| Font (mono/code) | IBM Plex Mono → `ui-monospace, SFMono-Regular, Menlo, Monaco, Consolas, monospace` |
| Font (display, optional) | Source Serif 4 → `Georgia, serif` — sparingly, hero pull-quotes only |
| Token source (SSOT) | `brandbook/tokens/tokens.css` — linked via relative `<link>`; **read, never redefine** |
| Theming | `[data-theme="light"|"dark"]` + `@media (prefers-color-scheme: dark)`; hand-authored dark hexes. NO `filter: invert()` |

## Spacing Scale

Declared values, copied verbatim from `tokens.css` `--cw-space-*` (all multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| `--cw-space-xs` | 4px | Icon gaps, inline padding, swatch label gaps |
| `--cw-space-sm` | 8px | Compact element spacing, pill padding |
| `--cw-space-md` | 16px | Default element spacing, card padding |
| `--cw-space-lg` | 24px | Sub-section padding |
| `--cw-space-xl` | 32px | Section padding (`.cwb-section`) |
| `--cw-space-2xl` | 48px | Major section breaks |
| `--cw-space-3xl` | 64px | Page-level / header spacing |

Exceptions: **none for spacing** — every step is a multiple of 4. (Note: `--cw-radius-sm: 5px` and `--cw-focus-offset: 3px` are radius/focus scalars, not spacing, and are DOCUMENTED divergences DIV-7 in `notes/decision-log.md`; do not "fix" them here — zero-drift on tokens is a milestone invariant.)

## Typography

Copied verbatim from `tokens.css`. Exactly 4 sizes, exactly 2 weights.

| Role | Token | Size | Weight | Line Height |
|------|-------|------|--------|-------------|
| Label | `--cw-font-size-label` | 14px | 400 (`--cw-font-weight-regular`) | 1.35 (`--cw-line-height-label`) |
| Body | `--cw-font-size-body` | 16px | 400 (`--cw-font-weight-regular`) | 1.5 (`--cw-line-height-body`) |
| Heading | `--cw-font-size-heading` | 20px | 600 (`--cw-font-weight-semibold`) | 1.2 (`--cw-line-height-heading`) |
| Display | `--cw-font-size-display` | 28px | 600 (`--cw-font-weight-semibold`) | 1.15 (`--cw-line-height-display`) |

Weights: **regular 400 + semibold 600 only.** Never ship ultra-light UI/body text (WCAG anti-aliasing rule, `prompts:657`). Never use muted text below 14px (`prompts:662`). Prefer real text over images of text.

## Color

60 / 30 / 10 split, expressed through semantic tokens (values shown light → dark).

| Role | Token | Value (light → dark) | Usage |
|------|-------|----------------------|-------|
| Dominant (60%) | `--cw-surface-bg` | `#fffdf8` (paper) → `#07131a` (night) | Page background, open field behind logo marks |
| Secondary (30%) | `--cw-surface-panel` | `#ffffff` → `#10232c` | Cards, swatch panels, demo containers, code blocks |
| Accent (10%) | `--cw-accent` | `#0e7c86` (teal) → `#9adbcf` (mint) | See reserved-for list below |
| Destructive | `--cw-danger` / `--cw-button-danger-bg` | `#b83232` → `#ffb3b3` | Demonstrated danger/error component state only |

**Accent (`--cw-accent`) reserved for — explicit list, never "all interactive elements":**
1. Primary button surface (`--cw-button-primary-bg`) in the component-state showcase
2. The `.is-selected` component-state indicator (inset ring)
3. The integrated accent stroke of the brand mark when rendered on theme
4. Section-anchor / active-nav emphasis in the book chrome

Elements that are interactive but do **not** use accent: links use `--cw-link-fg` (`#0e5f67` → `#9adbcf`); focus rings use `--cw-focus` (`--cw-blue #2d6cdf` light → `--cw-brass #d6a84f` dark); hover/active surfaces use the `--cw-control-hover`/`--cw-control-active` layer.

**Status triads** (never color-alone — always pair with a label + icon, `prompts:663-664`). Each has `-text` / `-surface` / `-border`, both themes, from `tokens.css`:

| Status token family | Pill role (per `prompts:669-679`) |
|---------------------|-----------------------------------|
| `--cw-status-success-*` | Succeeded — green pill |
| `--cw-status-warning-*` | Suppressed / Expired — amber/brown pill (+ outline for Expired) |
| `--cw-status-danger-*` | Failed — red pill |
| `--cw-status-info-*` (`--cw-info` → `--cw-blue`) | Enqueued — blue pill |
| `--cw-status-neutral-*` | Planned / Cancelled — neutral pill (+ outline for Cancelled) |
| `--cw-violet` (`#6d5df6`) | Sending — violet pill |

## Copywriting Contract

The book both **documents** voice rules and **demonstrates** them in live microcopy. All copy lifts from `prompts/chimeway-brand-book.md` (canonical source) — do not invent new examples.

| Element | Copy |
|---------|------|
| Primary CTA (demonstrated + doc-CTA rule) | Developer-to-developer, never a sales CTA. Demonstrated button label: `install chimeway`. Rule: no "Supercharge…/omnichannel/journey" CTAs (`prompts:1799-1801`) |
| Theme toggle control | Tri-state: `light` · `dark` · `system` (`data-cwb-theme` buttons; "system" removes `data-theme` and defers to `prefers-color-scheme`) |
| Empty state heading | `No deliveries yet` |
| Empty state body | `Trigger an event to see it traced here.` (calm, explains next step — voice principle §2 "explain decisions") |
| Error state (named template) | **"Chimeway error message pattern: what happened → why it matters → how to fix"** (VOICE-02). Canonical example: `Delivery suppressed: recipient disabled email for `invoice.paid`.` (`prompts:1375`). Avoid: "This chime did not ring." |
| Destructive confirmation | N/A — the static book has **no destructive actions**; it only *renders* the danger/error component state (`--cw-button-danger-*`). Document the danger visual; do not wire a real destructive flow |

**Voice-by-context matrix (VOICE-01) — each with good/bad, from `prompts:1349-1409`:**

| Context | Good (lift verbatim) | Bad (show as don't) |
|---------|----------------------|---------------------|
| Docs | "Use an idempotency key when the same domain event may be retried…" | "Chimeway magically knows when not to duplicate messages." |
| Errors | "Delivery suppressed: recipient disabled email for `invoice.paid`." | "This chime did not ring." |
| Marketing/Homepage | "Notifications are easy to send and hard to explain. Chimeway gives every event, recipient, delivery, and attempt a place in your app's database…" | "Supercharge your user engagement with next-generation omnichannel notification journeys." |
| CLI / Admin UI | "Provider accepted the push notification. Device display is not guaranteed by the provider response." | "Push delivered." |

**Naming & CTA rules (VOICE-03):**
- Graphic wordmark: lowercase `chimeway` (friendliness + package-name alignment, `prompts:515`).
- Prose: title-case **Chimeway** (`prompts:517-519`).
- Package names lowercase (`chimeway`, `chimeway_ecto`, …); modules `Chimeway.*`.
- Preferred vocabulary: notification, event, recipient, channel, route, delivery, attempt, trace, policy, suppression, digest, inbox, durable, explainable, inspectable, app-owned, code-first (`prompts:315-343`).
- Banned vocabulary: blast, campaign, journey, engagement automation, funnel, omnichannel, AI-powered, magical, zero-config (unless literally true), enterprise-grade (unless substantiated) (`prompts:359-381`).

## Component States & Interaction Contract

All nine states render **statically, without interaction**, via `.is-*` forcing classes that duplicate the real pseudo-class rule (STATE-01). Each demoed twice: a live interactive control **and** a frozen `.is-*` copy labelled with its state name.

| State | Static class | Token(s) driving it |
|-------|-------------|---------------------|
| hover | `:hover` / `.is-hover` | `--cw-control-hover` |
| focus | `:focus-visible` / `.is-focus` | `outline: --cw-focus-offset solid --cw-focus`, offset `--cw-focus-offset` (visible, not obscured — SC 2.4.7) |
| active | `:active` / `.is-active` | `--cw-control-active`, `--cw-motion-pressed` |
| disabled | `:disabled` / `.is-disabled` | `--cw-control-disabled-bg` / `--cw-control-disabled-fg`, `cursor: not-allowed` |
| loading | `.is-loading` | spinner/pulse composed from `--cw-fg-muted` + `--cw-motion-fast` |
| error | `.is-error` | `--cw-status-danger-*` triad + label + icon (never color-alone) |
| empty | `.is-empty` | `--cw-fg-muted` on `--cw-surface-panel` + empty-state copy above |
| skeleton | `.cwb-skeleton` | pure-CSS shimmer over `--cw-control-disabled-bg`↔`--cw-surface-hover`; `@media (prefers-reduced-motion: reduce)` disables animation (A11Y gate, Phase 86) |
| selected | `.is-selected` | `--cw-surface-active` + inset `2px` ring in `--cw-accent` |

**Interaction contract for the book's own live controls:**
- Theme toggle: single inline classic `<script>` (only JS that runs under `file://`); writes `data-theme` on `document.documentElement`; "system" removes the attribute.
- Live contrast matrix: reads tokens via `getComputedStyle` on a painted probe (resolves `var()` aliases + active theme); recomputes on `data-theme` flip and on `prefers-color-scheme` change; WCAG relative-luminance formula inline (no library). AA thresholds: ≥4.5:1 normal text, ≥3:1 large text / non-text UI.
- Interactive targets ≥24×24px (SC 2.5.8, Phase-86 gate — build to it now).

## Do / Don't Visual Pairs (STATE-02)

Three paired mis-use demonstrations, each a `.cwb-do` / `.cwb-dont` side-by-side:

| Pairing | Do | Don't (source) |
|---------|-----|----------------|
| Logo | Mark + wordmark as one unit on open field; inverse mark reads with no backdrop | Rectangular/enclosing background cage behind the mark; icon-left/text-right split (`prompts:561-582`, LOGO-05) |
| Color | Status conveyed by color **+** label + icon; body text = `--cw-ink` on `--cw-paper` | Brass text on paper for body copy; color-alone status (`prompts:661-663`) |
| Spacing | Consistent `--cw-space-*` rhythm; documented clear-space around the mark | Cramped/ad-hoc gaps; sub-minimum logo clear-space |

## Registry Safety

| Registry | Blocks Used | Safety Gate |
|----------|-------------|-------------|
| none | none — zero third-party runtime code | not applicable |

**Security posture (V14 Supply Chain):** the artifact ships **no CDN `<script src>`, no npm deps, no `fetch`, no external modules.** This is the primary security property and is itself brand-worthy ("nothing to slopsquat, nothing to CSP-exempt"). The `scripts/brandbook-guards.sh` negative greps must enforce that no future edit can add a CDN script, a `fetch(`, an `XMLHttpRequest`, a `type="module"`, or a cross-file `<use href="*.svg#…">`.
