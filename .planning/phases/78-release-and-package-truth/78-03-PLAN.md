<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| dependency metadata -> Hex package build | Mix dependency metadata controls whether a package can be built and published. |
| source tree -> unpacked Hex artifact | Package whitelist controls which public truth files reach Hex consumers. |
| local artifact contract -> release gate | `mix ci.verify_gates` and `mix verify.parity` must catch artifact drift before publish. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-78-09 | Denial of Service | `mix hex.build --unpack` | mitigate | Remove the Sigra overridden dependency blocker and verify the default build succeeds without skip envs. |
| T-78-10 | Tampering | package files whitelist / unpacked artifact | mitigate | ExUnit artifact contract asserts whitelist roots and `mix verify.parity` proves the same local unpack behavior. |
| T-78-11 | Spoofing | unpacked package source links | mitigate | Artifact contract reads unpacked `mix.exs` and README and requires `https://github.com/szTheory/chimeway`. |
| T-78-12 | Spoofing | unpacked sibling guide install status | mitigate | Artifact contract reads unpacked admin/inbox guides and requires preview/path status for unpublished siblings. |
| T-78-13 | Information Disclosure | publish credentials during artifact proof | mitigate | Local artifact proof uses `mix hex.build --unpack` only; it never sets or prints `HEX_API_KEY`. |
| T-78-SC | Tampering | package-manager installs | accept | No new dependencies are installed; existing dependency metadata is narrowed to satisfy Hex package rules. |
</threat_model>
