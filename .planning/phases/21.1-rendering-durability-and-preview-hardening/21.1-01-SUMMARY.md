# 21.1-01: Render Identity Durability

## Purpose
Persist a durable render declaration on notifications and remove planner-time rendering re-entry.

## Implementation
- Added `render_channels` map field to `Chimeway.Notifications.Notification`.
- Created Ecto migration `20260428201500_add_render_channels_to_chimeway_notifications.exs`.
- Updated `Chimeway.Trigger` to persist sanitized `render_channels` at trigger time, keeping rendered body payloads excluded.
- Changed `Chimeway.DeliveryPlanning` to exclusively read the requested channel from `notification.render_channels` and never re-enter `Notifier.resolve_rendering/3`.
- Replaced hidden rendering fallback with explicit tagged errors: `{:error, {:missing_render_declaration, channel}}`.
- Updated numerous test fixtures across the suite to supply `render_channels` and validate the new durable render planning contract.
