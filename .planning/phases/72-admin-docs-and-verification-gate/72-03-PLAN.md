## Trust Boundaries

| Boundary | Description |
|---|---|
| Maintainer shell to project verification | `mix verify.admin` runs package, demo-host, npm, and browser commands from the repo root. |
| CI runner to dependency registries | CI installs Elixir deps and npm Playwright dependencies. |
| CI gate to release readiness | `ci-gate` decides whether all required lanes succeeded. |
| Browser smoke artifacts to CI logs | Failed browser tests may retain traces/screenshots containing rendered admin content. |

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|---|---|---|---|---|
| T-72-03-01 | Tampering | `mix verify.admin` alias | mitigate | Alias must explicitly run root admin tests, full package tests, demo-host mounted admin test, npm install, Chromium install, and the Playwright smoke; release contracts assert alias presence. |
| T-72-03-02 | Repudiation | CI/local parity | mitigate | `verify_admin` CI job must invoke `mix verify.admin`; release-gate tests assert job and command presence. |
| T-72-03-03 | Denial of Service | ci-gate omission | mitigate | Add `verify_admin` to `ci-gate.needs`, env map, and lane loop; update release-gate expected lane list from 11 to 12 lanes. |
| T-72-03-04 | Information Disclosure | Browser traces/screenshots | mitigate | Browser smoke from Plan 72-02 uses deterministic demo data and privacy assertions; `verify.admin` must not add extra sensitive fixtures or raw trace logging. |
| T-72-03-SC | Tampering | npm install through verify alias | mitigate | `@playwright/test` package was approved in the Phase 72 Package Legitimacy Audit; alias uses lockfile via `npm ci` and no unapproved npm packages. |
