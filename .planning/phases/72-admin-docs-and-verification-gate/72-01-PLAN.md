<threat_model>
## Trust Boundaries

| Boundary | Description |
|---|---|
| Adopter docs to production host setup | Maintainers may copy guide snippets into production Phoenix apps. |
| Host auth policy to `chimeway_admin` | Host owns actor, tenant, and recovery authorization decisions. |
| Core/admin redaction contracts to docs claims | Docs must not overpromise privacy or expose examples with sensitive payload data. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|---|---|---|---|---|
| T-72-01-01 | Elevation of Privilege | Admin auth guide snippet | mitigate | Guide must document `ChimewayAdmin.Auth.authorize/3`, production fail-closed behavior, `{:error, :unauthorized}`, and replacement of permissive demo auth before shipping. |
| T-72-01-02 | Information Disclosure | Redaction guide claims | mitigate | Guide and doc contracts must state operator surfaces do not expose raw payloads, render data, provider bodies, tokens, secrets, auth codes, or full recipient PII. |
| T-72-01-03 | Tampering | Recovery permission docs | mitigate | Guide must name `:list_recovery_candidates`, `:recover_delivery`, and `:recover_event` as host-owned authorization decisions, not broad blanket admin powers. |
| T-72-01-04 | Information Disclosure | Tenant/context docs | mitigate | Guide must document `current_actor`, `chimeway_admin_tenant_id`, and that tenant membership/policy validation remains host-owned. |
| T-72-01-SC | Tampering | Package manager installs | accept | This plan has no package-manager install tasks. |
</threat_model>
