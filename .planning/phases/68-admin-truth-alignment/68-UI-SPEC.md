## Color

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `#fffdf8` light / `#07131a` dark | Admin background and full-page shell |
| Secondary (30%) | `#ffffff` light panel, `#f7f4ea` soft panel / `#10232c` dark panel, `#0b1b23` dark soft panel | Cards, sidebar, rows, tables, empty states |
| Accent (10%) | `#0e7c86` light / `#9adbcf` dark | Primary command-center CTA, active nav background tint, hover tint, eyebrow/kicker emphasis |
| Destructive | `#b83232` | Recovery submit action only |

Accent reserved for: `Open Trace Lookup`, active sidebar item, nav/row hover tints, page eyebrow text, command-center headline kicker, non-destructive primary submit buttons for search/inspect flows.

Semantic status colors: use existing `#0b7a50` for succeeded/sent/read/seen, `#8a5a00` for suppressed/warning/event, `#2d6cdf` for pending/delivery/unread, and `#b83232` for failed/cancelled/danger. Do not use status colors as general decoration.

## Copywriting Contract

| Element | Copy |
|---------|------|
| Primary CTA | Open Trace Lookup |
| Empty state heading | No matching admin rows |
| Empty state body | Try the exact recipient identity, correlation ID, or a shipped admin section from the sidebar. |
| Error state | Admin view unavailable. Check the mounted route, host auth/session context, and `:chimeway_admin` path prefix before retrying. |
| Destructive confirmation | Recover this event/delivery: require selecting one eligible row, reviewing type/key/reason/correlation, entering a recovery reason, then submitting `Recover this event` or `Recover this delivery`. |

Phase 68 page labels are locked:

| Route | Page Label | Interaction Contract |
|-------|------------|----------------------|
| `/admin/chimeway` | Command Center | Landing page; Trace Lookup is the headline job and primary CTA. |
| `/admin/chimeway/traces` | Trace Lookup | Search by recipient ID or correlation ID; results open Trace Detail. |
| `/admin/chimeway/deliveries/:delivery_id` | Trace Detail | Explains one delivery timeline. Keep label in docs/nav tests even though it is not a sidebar item. |
| `/admin/chimeway/feed` | Feed Debug | Operator lifecycle inspection by recipient; never describe as the end-user inbox surface. |
| `/admin/chimeway/definitions` | Definitions | DB-inferred durable notification key/version usage; never claim code-registry skew detection. |
| `/admin/chimeway/health` | Health | Lifecycle outcome overview and problem trace entry point. |
| `/admin/chimeway/recovery` | Recovery | Eligible recovery queue; action-bearing behavior is existing UI only, with Phase 70 safety hardening deferred. |

Docs/demo copy must name all seven pages above and must not describe the shipped admin as "trace lookup only" or say Health, Definitions, Feed Debug, or Recovery are out of scope.
