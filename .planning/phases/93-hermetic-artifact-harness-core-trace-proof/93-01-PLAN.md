## Flagged assumptions from the spec-less edge probe

1. **[ASSUMPTION — PROOF-01 / unclassified]** The artifact boundary applies specifically to `:chimeway`; the clean host may declare `ecto_sql ~> 3.11` and `postgrex >= 0.0.0` directly because its Repo must compile without relying on transitive visibility.
2. **[ASSUMPTION — PROOF-01 / unclassified]** A path dependency targeting the directory produced by `mix hex.build --unpack` is the intended install proof; copying that artifact again or creating a local Hex registry would add no provenance value.
3. **[ASSUMPTION — PROOF-02 / unclassified]** Existing `DATABASE_URL` or root Repo configuration may supply connection credentials/host/port, but the generated consumer must force `url: nil` and replace only the database with its unique owned name.
4. **[ASSUMPTION — CORE-01 / unclassified]** One in-app channel rendered by the adopter notifier under Sync + Logger is the thinnest complete Core lifecycle and yields exactly one delivery suitable for public explanation.
5. **[ASSUMPTION — PROOF-03 / adjacency + ordering]** Required public timeline events are asserted as an ordered subsequence (`:event_created`, `:notification_created`, `:delivery_planned`, `:attempt_recorded`), not as adjacent entries, so additional public lifecycle events do not create false failures.
6. **[ASSUMPTION — PROOF-03 / empty]** An empty delivery-ID list, empty timeline, or nil `last_attempt` is a hard proof failure with an actionable message; the proof does not substitute an event-level or database query.
7. **[ASSUMPTION — PROOF-03 / concurrency]** The expensive release-gate contract remains `async: false`; unique temp roots and database names prevent cross-run collisions, but simultaneous stress execution is not itself a Phase 93 acceptance requirement.

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Repository source -> unpacked package -> generated consumer | The consumer must trust only files included in the built artifact and must not silently reach back into the checkout. |
| Ambient process environment -> generated PostgreSQL config | `DATABASE_URL` can supply connection coordinates but must not override the fixture-owned database or leak credentials. |
| Generated consumer -> public Chimeway APIs | Host-owned notifier/inputs cross into Chimeway through `trigger/3`; lifecycle evidence returns only through `Traces.explain_delivery/1`. |
| Public explanation -> terminal/stdout and ExUnit failure output | Safe public structs can still disclose unnecessary recipient or operational fields if serialized wholesale. |
| Test fixture -> PostgreSQL server and system temp directory | Cleanup must act only on the exact unique resources created by this invocation. |
