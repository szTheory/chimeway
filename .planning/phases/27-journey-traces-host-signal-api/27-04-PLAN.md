<objective>
Make the Phase 27 migration upgrade-safe and close the tenant_id empty-string asymmetry between WorkflowRun and Signal changesets.

Purpose: Without these fixes, Phase 27 cannot deploy to any host with pre-existing workflow_runs rows (CR-01), and an empty tenant_id can be persisted through WorkflowRun.changeset and silently fail downstream tenant lookups (WR-03). This plan is the prerequisite for plans 27-05 and 27-06 — schema correctness must precede the tenant-threading and routing fixes.
Output: A migration that adds nullable, backfills, then enforces NOT NULL within a single migration; backfills pending_signals; and a WorkflowRun changeset that validates tenant_id non-empty.

**Closes gaps:** CR-01 (BLOCKER), WR-03 (WARNING), IN-04 (related backfill on pending_signals).
</objective>
