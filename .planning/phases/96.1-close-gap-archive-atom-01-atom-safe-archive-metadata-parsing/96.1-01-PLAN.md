<interfaces>
The stable production seam is `Chimeway.AdoptionProof.ArtifactArchive.with_validated_archive/3 :: (Path.t(), String.t(), (Path.t() -> term())) -> {:ok, term()} | {:error, String.t()}`. It reads one bounded immutable archive binary, compares SHA-256, extracts `metadata.config` and `contents.tar.gz` in memory, validates metadata and the materialized package root, then invokes the callback once.

`scripts/prove-adoption-paths.exs` dynamically applies `with_validated_archive/3`; `scripts/prove-accrue-consumer.exs` calls it directly. Neither caller changes in this phase.

The current real `mix hex.build` metadata uses repeated dot-terminated two-tuples with binary keys and values composed of UTF-8 binaries, proper lists, nested two-tuples, and fixed booleans. The selected keys are `<<"name">>`, `<<"version">>`, and `<<"files">>`.
