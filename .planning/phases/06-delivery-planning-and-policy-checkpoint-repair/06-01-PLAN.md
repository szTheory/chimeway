```elixir

plan_notification(notification, opts \\ []) :: {:ok, [Delivery.t()]} | {:error, term()}
```
2. Derive channels using this rule order:
   - If notifier in opts exports `channels/2`, call `notifier.channels(trigger_params, recipient_map)`.
   - Else fallback to `[:in_app]`.
3. Normalize channels:
   - accept atom/string values
   - convert to unique channel strings
   - sort for deterministic output
4. For each normalized channel, call `Deliveries.plan_delivery(notification.id, channel)`.
5. Immediately run planning checkpoint:
```elixir
case Policy.evaluate(delivery, []) do
  {:ok, :proceed} -> {:ok, delivery}
  {:suppress, reason} -> Deliveries.suppress_delivery(delivery, reason, checkpoint: :planning)
end
```
6. Return all planned rows (both pending and suppressed) in deterministic order.
7. If notifier `channels/2` returns `{:error, reason}`, stop planning and return `{:error, {:channels_resolution_failed, reason}}`.
