## Spacing Scale

Declared values (must be multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Field hints, small inline gaps, status dot gap |
| sm | 8px | Compact row gaps, nav item spacing, copyable-ID padding |
| md | 16px | Default card padding, list gaps, form gaps |
| lg | 24px | Hero/detail panel padding, sidebar padding, page header separation |
| xl | 32px | Main content padding on desktop, two-column grid gaps |
| 2xl | 48px | Major vertical section separation when needed |
| 3xl | 64px | Reserved for page-level spacing only; avoid inside cards and tool surfaces |

Exceptions: icon-free controls must keep a minimum height of 40px; pointer touch targets that trigger recovery or navigation must be at least 44px on mobile; 1px borders and 3px focus outlines are allowed; status pills may use 26px minimum height because they are read-only.

Implementation contract: expose these as `--cw-space-*` tokens under `@layer cw.tokens` and consume semantic spacing tokens in `.cw-shell`, `.cw-sidebar`, `.cw-main`, `.cw-card`, `.cw-search-form`, `.cw-row`, `.cw-table`, `.cw-summary-list`, `.cw-copy-id`, and `.cw-metric-grid`.

## Typography

| Role | Size | Weight | Line Height |
|------|------|--------|-------------|
| Body | 16px | 400 | 1.5 |
| Label | 14px | 600 | 1.35 |
| Heading | 20px | 600 | 1.2 |
| Display | 28px | 600 | 1.15 |

Typography contract:

- Use exactly these four font-size tokens for shared components: `--cw-font-size-label: 14px`, `--cw-font-size-body: 16px`, `--cw-font-size-heading: 20px`, `--cw-font-size-display: 28px`.
- Use exactly two weights in the design-system contract: `--cw-font-weight-regular: 400` and `--cw-font-weight-semibold: 600`.
- Remove viewport-scaled heading sizing from shared admin primitives; responsive layout may change wrapping and grid structure, not font size.
- Long notification keys, recipient IDs, delivery IDs, correlation IDs, and code values must use `overflow-wrap: anywhere` and `min-width: 0` in their containing flex/grid cells.

Source: REQUIREMENTS DES-03, Phase 69 CONTEXT D-03/D-07, and existing `.cw-copy-id`, `.cw-summary-list`, row, table, and header surfaces.

## Color

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | light `#fffdf8`; dark `#07131a` | Root page background and broad reading surface |
| Secondary (30%) | light `#ffffff` / `#f7f4ea`; dark `#10232c` / `#0b1b23` | Cards, sidebar, nav, rows, inputs, tables, summary lists |
| Accent (10%) | light `#0e7c86`; dark/system-dark `#9adbcf` | Primary CTA, active nav item, focus-adjacent highlights, selected rows, small emphasis labels |
| Destructive | `#b83232` | Recovery submit action and destructive/error state only |

Accent reserved for: primary CTA background, active nav background/text treatment, focused or selected row state, `.cw-eyebrow`/kicker labels, and status/info emphasis when it represents navigation or selection. Accent must not be used for every link, all body text, or decorative gradients that compete with operator data.

Semantic color contract:

- Keep `data-cw-theme="light|dark|system"` on `.chimeway-admin`; `system` resolves through `prefers-color-scheme`.
- Add explicit tokens for foreground, muted text, border, panel, panel-soft, hover, active, focus ring, focus halo, and disabled states.
- Add status tokens for success, warning/suppressed, danger/failed, info/pending, neutral/unknown, plus each status surface/border/text pair.
- Meet WCAG 2.2 AA: 4.5:1 for normal text, 3:1 for large text, 3:1 for focus indicators and non-text UI controls.
- Do not rely on `color-mix()` at component call sites for contrast-critical states; derived colors must be assigned to named state tokens.

Source: Phase 69 CONTEXT D-03/D-05 and REQUIREMENTS DES-01/DES-02.

## Interaction Contract

| Surface | Contract |
|---------|----------|
| Theme | Root remains `<main class="chimeway-admin" data-cw-theme={@theme}>`; light, dark, and system must have matching hover, focus, active, status, input, and table states. |
| Navigation | Sidebar collapses to a top stacked region below 900px; nav items have stable 44px mobile hit targets and `aria-current="page"` on active item. |
| Search forms | One-column layout below 900px; inputs and submit button keep stable 40px minimum height; labels remain above controls. |
| Rows and row buttons | Rows use `min-width: 0`, wrapping metadata, and non-layout-shifting hover/active states. No transform on keyboard focus. |
| Tables | Tables stay horizontally scrollable when needed; cell content wraps where safe and never overlaps adjacent cells. |
| Copyable IDs | ID containers wrap and truncate only by design; full value remains available through the existing title attribute. |
| Focus | `:focus-visible` uses a 3px outline with 3px offset and a tokenized color that passes 3:1 against adjacent colors. |
| Motion | Motion is CSS-only for Phase 69; transitions are 120ms for color/border/background and 80ms for pressed feedback. No layout-affecting animation is required. |
| Reduced motion | `@media (prefers-reduced-motion: reduce)` sets animation/transition duration to near-zero and `scroll-behavior: auto`. |

## Copywriting Contract

| Element | Copy |
|---------|------|
| Primary CTA | Open Trace Lookup |
| Empty state heading | No recoverable work |
| Empty state body | Nothing currently meets the recovery safety threshold. |
| Error state | Recovery failed. The row may no longer be eligible; refresh Recovery and try again with a current candidate. |
| Destructive confirmation | Recover this event/delivery: keep the visible button label `Recover this {type}` and require the existing `Recovery reason` field before submission. |

Copy source: existing `DashboardLive`, `TraceSearchLive`, and `RecoveryLive`. Phase 69 may polish styling and layout around these strings but must not introduce Phase 70 authorization/tenancy behavior or Phase 71 redaction/explainability copy changes.
