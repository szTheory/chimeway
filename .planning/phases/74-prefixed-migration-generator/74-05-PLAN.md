| Boundary | Description |
|---|---|
| fixture subprocess -> committed fixtures | Real generated host migrations become test fixtures and product contracts. |

|---|---|---|---|---|
| T-74-15 | Tampering | generated prefixed output | mitigate | Static contract fails on missed bare Chimeway-owned Ecto and raw SQL relation references. |
| T-74-16 | Tampering | public legacy output | mitigate | Golden and static checks prove public mode emits unprefixed legacy migrations without unsafe Ecto false-prefix options. |

| T-74-18 | Repudiation | CI/local gate parity | mitigate | `ci.install_golden` and `install_golden_contract` run the same named proof set. |
| T-74-19 | Information Disclosure | fixtures and stdout | mitigate | Fixture output is structural migration code and command status only; no payload or operator surface is introduced. |
| T-74-SC | Tampering | package manager surface | accept | This plan installs no new packages. |
</threat_model>
