<threat_model>
## Trust Boundaries

| Boundary | Description |
|---|---|
| Chimeway verifier -> CrossWake checkout | Chimeway may trust CrossWake semantics only at the declared canonical remote and immutable selected SHA. |
| CrossWake canonical bytes -> retained Chimeway bundle | Authority bytes are ephemeral; only validated safe digests/opaque references cross into Chimeway evidence. |
| Host/device facts -> proof records | Raw credentials, tokens, identity, device data, payloads, logs, and paths are untrusted and excluded. |
| Observer -> visible-alert attestation | One subjective state is accepted as a separate attestation and cannot create machine facts. |
| Publisher -> evidence filesystem | A fresh run may create a new bundle but may not replace any prior destination. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|---|---|---|---|---|---|
| T-103-01 | Spoofing/Tampering | CrossWake source binding | high | mitigate | Require approved publication to the named canonical ref, resolve the sole authority-file SHA, prove that ref advertises it, fetch it into a detached clean checkout, run the source-owned verifier there, and require revision/digest agreement before validation. |
| T-103-02 | Elevation of Privilege | owner-qualified facts | high | mitigate | Closed ordered facts and exact expected owners prevent Chimeway from asserting permission, registration authority, or protected activation. |
| T-103-03 | Information Disclosure | physical bundle and errors | high | mitigate | Exact allowlists plus recursive D-08 scans reject sensitive keys/values; returned failures contain only PP-* rule IDs and bounded paths. |
| T-103-04 | Tampering/Repudiation | bundle publication | high | mitigate | Digest every component, bind the completion marker and run_ref, use exclusive atomic creation, and fail on any existing destination. |
| T-103-05 | Spoofing | visible-alert attestation | high | mitigate | Keep attestation separate, bind it to the machine-envelope digest/run_ref, accept only three states, and allow promotion only for externally supplied observed. |
| T-103-06 | Information Disclosure | credential-free verification | high | mitigate | The Threshold-A task uses no Apple/APNs signing inputs and scans output for retained credential or authority material. |
