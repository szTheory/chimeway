    - Providing no rules on a `:not_branchable_yet` outcome continues to return `{:noop, run, :no_progress_rules}` or `{:noop, run, :no_matching_progress_rule}`.

    2. Refactor `evaluate_step/5` to evaluate rule matches via a unified `match_rule` instead of `match_on_outcome`.
    3. `match_rule` must find the first rule where `kind in ["on_outcome", "stop"]` matching the outcome string.
    4. Implement `stop_run(repo, run, step, delivery, rule, outcome, evidence, now)` following the exact transaction/transition pattern as `enter_waiting`, transitioning `run` state to `:stopped` with reason `"workflow_stopped"`.
