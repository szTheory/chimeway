<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Mutable pathname → immutable package bytes | The caller may replace the path at any time; only one bounded read may become the validated package identity. |
| Compressed input → decompressed tar | A small gzip stream can expand disproportionately; byte accounting must stop inflation before an oversized output is accumulated. |
| Tar headers → memory/filesystem | Declared member size and count can exhaust resources before ordinary path/type validation or writes. |
