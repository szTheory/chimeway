<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Caller-supplied archive → private scratch | Archive bytes and the matching caller-supplied digest are untrusted; no member may create link semantics or escape the validator's directory. |
| Materialized package → validation and code loading | `File.read!/1` and `Code.require_file/1` follow filesystem links, so the tree must contain only contained regular files/directories before either operation. |
| Local contracts → live GitHub Actions | Source and ExUnit tests can prove archive and workflow structure, but only a real push/dispatch can prove the PostgreSQL-backed hosted job executes successfully. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-96-11 | Tampering / Elevation of Privilege | `extract_contents!/2` | critical | mitigate | Parse and allowlist member types before writes, reject all links/special entries, materialize regular bytes from memory only, and lstat the completed tree before validation or callback. |
| T-96-12 | Information Disclosure | `validate_root!/3` and proof-runner callbacks | high | mitigate | Prevent link-following reads/loads by rejecting special headers pre-write and allowing callbacks only after contained-tree lstat validation. |
| T-96-13 | Tampering | caller-provided SHA-256 | high | mitigate | Treat digest equality only as transport integrity; adversarial tests recompute a valid digest for malicious archives and still require rejection. |
| T-96-14 | Denial of Service | tar header scanner | medium | mitigate | Fail closed on malformed sizes, incomplete blocks/padding, unsupported extensions, and conflicting paths before allocation or filesystem materialization. |
| T-96-15 | Repudiation | GitHub adoption proof lane | medium | accept | Local code cannot attest a hosted run; keep the item visibly pending until a human records the actual GitHub Actions result and URL. |
</threat_model>
