## Trust Boundaries

| Boundary | Description |
|---|---|
| Host Auth callbacks/session → package assigns | Host-selected identity and tenant enter optional package state. |
| LiveView event → core lifecycle API | Browser-controlled params/UUIDs cross into tenant-scoped reads and mutations. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan | Residual Risk | Executable Verification |
|---|---|---|---|---|---|---|---|
| T-97-08 | Spoofing | Inbox/Admin mount context | high | mitigate | Require host auth success plus a concrete normalized tenant before assigning lifecycle authority. | Host callback correctness remains host-owned. | `mix verify.inbox &amp;&amp; mix verify.admin` |
| T-97-09 | Elevation of Privilege | LiveView event handlers | high | mitigate | Reuse validated tenant-bearing assigns/context on every event-time core call. | A compromised host auth module can authorize an incorrect tenant. | `mix cmd --cd chimeway_admin mix test --warnings-as-errors` |
| T-97-10 | Information Disclosure | Trace detail/recovery UI | high | mitigate | Pass tenant to detail/recovery APIs and preserve absent UI for wrong-tenant IDs. | Response timing is not claimed as a side-channel guarantee. | `mix cmd --cd chimeway_admin mix test test/chimeway_admin/live/trace_search_live_test.exs test/chimeway_admin/live/recovery_live_test.exs --warnings-as-errors` |
| T-97-11 | Tampering | Inbox mark-read events | medium | mitigate | Include assigned tenant in atomic core mutation and refresh from the same scope. | Concurrent same-tenant UI events remain governed by existing idempotent transition logic. | `mix cmd --cd chimeway_inbox mix test --warnings-as-errors` |
