## Trust Boundaries

| Boundary | Description |
|---|---|
| Public API options → lifecycle contexts | Host-supplied tenant scope authorizes row visibility/mutation. |
| UUID/recipient identifiers → atomic mutations | Attacker-controlled identifiers could target another tenant. |
| Recovery claim → reload/replan | Scope can be lost after the initial atomic predicate. |
