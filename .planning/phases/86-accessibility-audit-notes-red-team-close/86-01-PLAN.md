  <action>
    Create scripts/contrast-audit.sh: a dependency-free POSIX shell + awk script (no node,
    no npm, no network) mirroring the guard-script idiom (set -euo pipefail, pass/fail
    helpers). It parses --cw-* hex values from brandbook/tokens/tokens.css by awk
    field/substring extraction — never shell-eval of file contents — reading both the light
    :root block and the [data-theme="dark"] block, and case-normalizes each 6-digit hex.
    It reproduces the in-page formula verbatim: per sRGB channel divide by 255 then linearize
    with threshold 0.03928 (c/12.92 else ((c+0.055)/1.055)^2.4), luminance
    L = 0.2126*R + 0.7152*G + 0.0722*B, contrast = (Lhi+0.05)/(Llo+0.05). It prints a ratio
    (2 decimals, rounded half-up) plus an AA verdict (>=4.5 text, >=3 non-text, using >= at
    the threshold) for EVERY pairing named in D-01, for BOTH light and dark: text fg/bg pairs
    (ink/paper, muted/paper, link-fg/paper), status triads text/surface for success/warning/
    danger/info/neutral, status borders vs their surface ×5, panel borders (line/paper,
    border-strong/paper), focus rings (blue #2d6cdf light, brass #d6a84f dark), and both
    disabled pairs (control-disabled-fg/control-disabled-bg). Output rows are grouped by pair
    class then light-before-dark (stable, specified order). If any referenced token hex is
    absent/unparseable, fail loudly with a non-zero exit and an explicit message. No eval.
    Do NOT add the script path to any allowlist here (Plan 04 owns the allowlist widening).
  </action>
  <verify>
    <automated>chmod +x scripts/contrast-audit.sh && scripts/contrast-audit.sh; test $? -eq 0 && scripts/contrast-audit.sh | grep -Eq '3\.92' && scripts/contrast-audit.sh | grep -Eq '4\.95' && scripts/contrast-audit.sh | grep -Eq '1\.29'</automated>
  </verify>
  <acceptance_criteria>

    - Deleting/renaming a referenced token in a scratch copy makes the calc exit non-zero (fail-loud on missing token) — reasoned, not required to be executed against the real file.
  </acceptance_criteria>
