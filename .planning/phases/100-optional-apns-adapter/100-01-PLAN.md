## Trust Boundaries

| Boundary | Description |
|---|---|
| Host resolver → Chimeway adapter | Tenant-qualified transient token and opaque dispatcher reference enter only for one attempt. |
| Durable target → provider request | Safe stored intent becomes a closed payload and APNs headers after expiry and size validation. |
| Executor → provider | An attempt_started record must precede any request-emission authority. |
