<interfaces>
`Chimeway.Adapters.APNS.deliver/2` is the required entry point. It reconstructs intent, resolves the exact host binding, builds the closed payload, invokes `Chimeway.APNS.Transport.push/3`, privately classifies the result, and calls `Chimeway.APNS.BindingLookup.invalidate/1` only for a complete recognized 410 result.

`Chimeway.APNS.Transport.push/3` enters the real optional Pigeon path when no atom-valued `:apns_transport` override is configured. `pigeon_push/2` calls synchronous `Pigeon.push/3`; `PigeonAdapter.process_end_stream/2` correlates `stream.id`, projects bounded raw response facts into the queued notification, and completes the original callback.

The enabled consumer already provides `FakeHttp2Client`, a host-owned dispatcher, and raw `%Pigeon.Http2.Stream{}` injection without network I/O. Extend this fixture around the public adapter call instead of asserting only the intermediate `Transport.Result`.

Relevant external API coverage rows remain unchanged: integrate synchronous single-notification `Pigeon.push/3`, dispatcher selection, timeout, APNs 410 ExpiredToken/Unregistered, and known provider outcomes; retain the recorded opt-outs for async callbacks, batching, credentials/supervision, raw bodies, registration, and protected opens.
</interfaces>
</context>
